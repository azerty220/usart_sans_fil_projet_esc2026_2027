# usart_sans_fil_projet_esc2026_2027
Mise en place d'une communication sans fil USART avec un drône
Paramètres de l'USART : 

    Débit : 115 200 baud
    8 bits de données
    1 bit de parité (pair)
    1 bit de stop

Contraintes générales :

    Portée du système : 10m
    Durée du projet : 40h
    Budget : 250€
